# 口述史发布放行治理应用

本项目面向公共档案馆，将口述史受访者授权边界、录音片段敏感性、遮蔽整改、伦理复核与公开发布放行收束为一条可追溯流程。浏览器工作台可完成创建与修订发布案、冻结及差异确认授权边界、原子导入不重叠片段目录、冲突扫描统计与依据追溯、单项或同类批量整改、复核进度暂存、复核退回或批准，以及发布凭据包下载和本地分项校验。

应用采用单进程 Go 分层架构，不依赖外部数据库或 Node 构建链。业务提交写入 `data/oral-history-clearance.jsonl`：每条 JSON Lines 记录含连续序号、前序散列和当前散列，并在确认写入前同步文件。启动恢复会校验完整事件链；不完整尾记录或散列异常会让启动明确失败。

## 构建

```text
go build ./cmd/server
```

## 运行

```text
go run ./cmd/server -addr=127.0.0.1:19081
```

打开 `http://127.0.0.1:19081/` 使用工作台。默认监听地址为 `127.0.0.1:19081`，也可通过 `-addr=127.0.0.1:<port>` 指定回环地址；未提供 `-addr` 时，`PORT` 环境变量可指定绑定到 `127.0.0.1:<PORT>` 的端口。服务拒绝非回环监听地址。可用 `-journal=<path>` 指定事件日志。

## 测试与自检

运行全部回归测试：

```text
go test ./...
```

运行有界端到端自检。该命令会真实监听指定回环端口，经 HTTP 完成创建、授权、片段、扫描、整改、复核、批准和凭据校验，然后关闭服务并自行退出：

```text
go run ./cmd/server -addr=127.0.0.1:19081 -selfcheck
```

## HTTP 写入约定

所有 JSON 写入请求必须使用 `Content-Type: application/json` 并提供 `Idempotency-Key`。除创建发布案外，命令体还必须携带当前 `expectedVersion`；版本变化时接口返回 `version_conflict`，调用方应刷新发布案后再提交。授权差异和片段批次的 `/preview` 端点是无副作用查询，不要求幂等键，也不会改变聚合版本或事件日志。浏览器工作台自动遵循这些约定。

馆藏编号按去除首尾空白并统一为大写后的值建立唯一索引；服务启动恢复和每次提交都会重新守护该约束。授权清单、目标公开日期或片段目录变化后，旧扫描会显式标记为历史结论，并要求对全部未删除片段重新扫描。已签发凭据可通过详情页下载稳定 JSON 字节，并查看凭据范围、案卷修订、日志锚点和规范化摘要的逐项校验结果。
